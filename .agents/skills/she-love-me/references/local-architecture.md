# 本地控制台：模块、数据库与维护

用于用户要求维护 UI、增删模块、管理会话或迁移本地数据库时。以当前项目根目录为工作目录；公开源码工作区与私人运行部署必须隔离。维护公开代码不触发真实同步、导出或模型调用。

## 所有权

| 层 | 入口 | 拥有的数据 |
| --- | --- | --- |
| HTTP/安全 | `dashboard/app.py` | loopback、session、same-origin、固定路由与安全 DTO |
| 业务管理 | `dashboard/library_service.py` | 只读源摘要与用户偏好组合、可见性校验 |
| 持久管理仓储 | `dashboard/library/` | `data/private/library/library.sqlite3` |
| 可选模块策略 | `dashboard/modules.py` | 依赖、新任务准入；设置持久化在管理库 |
| 页面壳与共享服务 | `dashboard/static/core.js`、`shell.js` | 导航、DOM/API 工具；不依赖 AI 脚本存在 |
| 功能页面 | `app.js`、`analysis-ui.js`、`backup-ui.js`、`library-ui.js` | 档案、分析、备份、管理交互 |
| 搜索投影 | `dashboard/search.py` | 可重建的本机文本索引，保留中文子串检索语义 |
| 关系时间线统计 | `dashboard/relationship_timeline.py` | 无内容、无 I/O 的日期/频率/间隔统计；详情与分析预览共享 |
| 时间线证据约束 | `dashboard/timeline_schema.py` | 匿名样本证据、事件先后与关联校验、分段事件无损合并 |
| 时间线视图 | `dashboard/static/relationship-timeline.js`、`relationship-timeline.css` | 密度带、节点筛选/排序/分页、原生弹窗；不自行请求分析 |
| 本地流水线 | `scripts/run_local_pipeline.py` | 每一步执行前核对模块状态，输出聚合退出结果 |
| 快照 | `scripts/backup_wechat_local.py` | 内容寻址对象与不可变版本化清单 |

原文字、图片、音频继续是文件归档，不塞入管理数据库的 BLOB。媒体、语音、转写索引仍使用各自 SQLite 库，不在本轮重排身份或重新生成消息键。

## 管理数据库

表：`schema_migrations`、`conversations`（只读源摘要与独立用户字段）、`tags`、`conversation_tags`、`module_settings`、`audit_log`。

- 固定位置 `data/private/library/library.sqlite3`，无服务端密码或新依赖，私密管理数据仅留本机。
- `bundle_id` 沿用归档包身份，不用联系人显示名重新编码。同步刷新仅写 `source_json/source_missing`，不覆盖别名、备注、标签、置顶、隐藏标记或用户版本号。
- 每次管理修改携带 `expected_version`；版本冲突 HTTP 409，需刷新重读后决定，不能自动覆盖。
- 会话“移入回收站”仅设置 `hidden_at`；恢复仅清除此字段。没有物理删除聊天接口。源临时缺失不会删除管理状态。
- 标签删除是软删除，已有分配保留，标签可恢复。修改当前可用标签只替换可用标签关联，不能顺带清除不可见的已删标签关联。别名不改原联系人名，备注不进入 AI 样本。
- 审计只保留操作/字段名等元数据，不记录备注正文；它不是备注全文的自动撤销历史。需要恢复旧管理内容时使用备份恢复到新目录核对。
- Schema 迁移按序追加、校验 checksum、事务提交；不得改已应用 SQL，失败不能删除重建库。数据库不是可丢弃缓存。
- 使用短连接、事务和 `writer.lock` 协作写锁。当前小型管理库使用 SQLite 默认回滚日志；备份同时支持 SQLite WAL 的一致捕获。不要在持有管理锁时反向申请同步/附件锁。

手动刷新管理投影（不启动微信读取或 AI）：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\refresh_library.py
```

## 模块增删

可选 ID：`analysis`、`media`、`voice`、`sync`、`backup`，默认开启。`voice` 依赖 `media`。核心档案、认证、回收站、历史读取和备份核验不作为可关闭模块。

新增模块时：

1. 在 `dashboard/modules.py` 的 `DEFINITIONS` 登记 ID、中文说明和依赖。
2. 所有新任务入口调用 `ModuleRegistry.require(id)`；如参加每日流水线，在 `STEPS` 显式登记。不要只隐藏按钮。
3. 前端向独立 shell 登记功能生命周期/导航；共享 DOM、API 和格式工具，不依赖其他可选模块的全局对象。
4. 增加依赖冲突、关闭后的 HTTP/流水线拦截、无该脚本时壳仍能导航、移动布局测试。
5. 新持久数据加入备份时，同时更新版本化来源白名单、活 SQLite 清单及协作写锁；旧清单版本白名单保持不变。

移除功能先通过页面设置停用，不级联删除数据，也不中断在途操作。删除源码需同步移除路由/流水线/前端注册及依赖引用；若数据库仍留有该模块设置，先编写显式迁移，不能让未知设置被悄悄解释为开启。聊天物理清除属于独立操作，不能由“卸载模块”推定授权。

## 自动化与分析

既有 `export_all_local.ps1` 调用模块感知流水线：同步 → 媒体 → 语音 → 转写 → 分类 → 管理投影 → 备份。关闭某可选模块则跳过相应新步骤；各步失败会汇总为失败，不伪报完成，已归档内容仍尽量备份。模块设置损坏时停止准入，不静默使用默认开启。

克隆仓库没有预注册的定时任务；使用者需明确配置运行频率与入口。已有部署升级时可沿用原 PowerShell 入口，不要为模块升级重复创建自动化。流水线没有云端分析步骤。由于备份来源固定在活动项目内，若 `SHE_LOVE_ME_DATA_DIR` 指向不同目录，定时入口以 `DATA_ROOT_MISMATCH` 停止，不得忽略错误继续同步或把另一个数据库的默认开关当成用户设置。

AI 成功分段缓存与旧报告保留，不因产品更名清空或重跑。时间线提示词参与缓存身份，并单独封存为预览的 `prompt_revision`；版本改变后在消费预览前拒绝，不能以新版本全部命中缓存为由绕过重新确认。消息顺序与既有费用/分段上限保持不变。隐藏后旧预览在真正启动时再次被检查；未消费预览，不发起调用。正在运行的任务不因开关变化被强杀，取消仍走原来的安全接口。历史报告可查看不等于授权继续付费分析。

本机时间线可读取该归档完整的时间元数据计算最近记录，但这一范围外统计不能进入云端请求。模型仍只接收确认的样本/范围内统计；事件日期和匿名序号只能引用此次输入，不能反向查找未选消息。分段合并仅能为孤立事件补充关联，不能改写事件事实或已有关联，原因说明必须沿用原证据解释。旧报告缺少时间线时只在响应中补空结构，不修改历史文件。详细约束见 `relationship-timeline.md`。

## 验证与恢复

### UI 主题维护

主控制台最后加载 `dashboard/static/apple-ui.css`，统一系统字体、按钮、表单、分组面板与浅/深色语义颜色。新增模块复用其变量与按钮类，不要把白底或低对比辅助文字写死在功能代码中。设计原则与 Apple HIG 来源见 `docs/apple-ui-design.md`。

仅改 UI 时不重新导出聊天、不运行同步/备份或调用模型。已有独立图片 HTML 是私人归档原件，包含自己的 CSP，不因为控制台换肤而重写它们。页面验收使用 `tests/test_apple_ui.py` 等合成浏览器夹具，覆盖小屏、对比度、点击区域、键盘与授权未预选。

只在 `scripts/tmp` 的合成数据上做浏览器、云请求 mock 和 CRUD 测试，不打开真实聊天页面截图。完整测试设置 `SHE_LOVE_ME_UI_TESTS=1` 后运行 unittest，另运行 `node --test tests/test_catalog.cjs`。

v1 快照仍按原六个来源校验和恢复；v2 新增管理库目录。旧快照不包含升级后才建立的管理状态，恢复旧快照不能声称恢复了新备注。恢复工具只写 `backups/restored/<新ID>`，不会覆盖活动库。不要用丢弃搜索索引的办法修复管理库。
