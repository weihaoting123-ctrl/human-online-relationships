# v0.1.8 关系分析视角审查

状态：候选，未正式发布。[AI-05 / #36](https://github.com/weihaoting123-ctrl/human-online-relationships/issues/36) · [设计](../superpowers/specs/2026-09-15-relationship-analysis-views.md) · [计划](../superpowers/plans/2026-09-15-relationship-analysis-views.md)。只记录公开源码与完全合成的验证，不发布私人部署日志或截图。

## 实现与兼容

新增六个关系回顾视角及简短说明，默认关系全景。原生选择器沿用系统样式和主题；说明随选择更新，具备可访问描述与礼貌播报。固定 JSON 目录共享给页面及 Python；浏览器只保存显示字段，实际系统指导仅从可信源码读取。

分段和汇总使用同一视角指导，不允许请求覆盖。提示版本散列实际使用的两个系统提示，调用预算也包含追加文本；四种旧视角的指导为空，因此原提示和缓存算法保持一致。修改展示文字或其他视角的指导不作废无关缓存。旧报告保留名称、ID 和范围，重核时临时加入其旧选项；未知视角不静默替换。

切换视角使预览及两种费用/发送确认失效，不会自动发起模型调用。目录未加载或失败时禁止新预览，历史与配置仍可读取。独立审查发现并合成复现本机目录缺失会影响全站初始化，现已改为不可用状态及固定本机错误，不回显路径或坏内容，也不使用替代提示继续发送。另查出目录迟到阻挡作业/历史、提前解锁配置提交两个时序问题，补充失败用例后修复：目录独立加载，只更新标签和视角控制，不抢占其他流程的状态。

联系空白不等于现实失联；历史区间不能解释当前未联系原因。互动频率不等于感情强度，日期级样本不能估算精确回复速度。共同计划只有明确报告的后续才能标为已发生。输出 schema、证据约束、逐次授权与不自动重试规则不变。

## 交付边界

不读取真实聊天，不发送云分析，不变更凭据、模型、微信原始记录、同步、备份或数据库。私人部署只应用六个相关源码文件的精确增量，空闲时重启，保留原有无关差异和源码回退。部署合成验收另要求对齐已公开的提交后确认清除逻辑：响应丢失时不能残留重复计费勾选，未更改传输范围或新增调用。新的视角不是重新分析已有报告的授权。

v0.1.8 基于未发布的 v0.1.7 候选，不把基线失败的 CI 或本机通过当作正式发布。此次准备阶段核验到前序 #35 的 CI 仍有图表探针浏览器失败；与本次视角改动无关，不混入额外图表修复。当前候选及前序合并、标签和 Release 均须另行核验。
