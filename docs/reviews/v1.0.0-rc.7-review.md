This remains a release candidate, not formal 1.0 or verified contact identity.

## Cause and implementation

The previous image-only OCR tests could not detect a black window-DC surface.
The native reader now uses a desktop DC to copy only the prevalidated title
rectangle into a same-size in-memory bitmap. It never allocates a whole-screen
or whole-window image and has no body-search fallback.

Automatic, manual and repeated reads share DWM physical visual bounds. Only DIP
offsets and dimensions are scaled. The standard-layout guard requires outer and
visual top edges to agree; other top offsets are rejected, not guessed. Old
unversioned-coordinate preferences remain on disk but cannot be loaded as new
visual-frame preferences; explicit recalibration writes numeric-only v2 state.

Acquisition checks the active input desktop, complete single-monitor containment,
unique eligible process/window, supported version, visibility, foreground,
geometry, DPI and occlusion before and after copying. Incomplete enumeration
cannot establish a unique candidate. DCs/graphics and DPI context are released or
restored on failure. Failed images are disposed and never published to OCR.

## Regression and independent review

- RED: synthetic black window surface fails `COMPOSITED_TITLE_NOT_CAPTURED`;
  differing outer/visual bounds fail `VISUAL_BOUNDS_REQUIRED`. Top-offset and
  incomplete enumeration regressions also failed before their guards were added.
- The new native fixture replaces only Win32/process boundaries and bitmap
  allocation tracking. It executes production geometry, acquisition, validation
  and cleanup control flow; any remaining P/Invoke fails test isolation checks.
  All pixels, process identities, windows and names are invented.
- Capture, auto-calibration, native guard and real local WinRT-on-synthetic-image
  OCR suites: **27/27 pass**, no skips. Independent rerun: **39.653 seconds**.
- Desktop Node: **73/73 pass**; catalog: **8/8 pass**. Related reviewer Node subset:
  **31/31 pass**. UI fixed-error regression passed without preview/model requests;
  arbitrary exception text is not displayed.
- Real Electron main/preload with isolated synthetic worker/backend: **21 checks
  pass**, including preservation without reuse of legacy ROI, explicit numeric
  recalibration, candidate changes and unchanged cloud-confirmation boundaries.
- Full local Python/UI regression: **1,060 tests / 521.705 seconds**, no failures,
  nine conditional skips. Final real-Electron smoke rerun also passes all 21
  checks. Runtime title tests above have no skips.
- Independent review found a top-origin risk; it was fixed with the explicit
  standard-top guard and before/after failing fixtures. No remaining critical or
  important finding. The support limitation is documented. AI-assisted review
  is not a security audit or cross-device compatibility certification.
