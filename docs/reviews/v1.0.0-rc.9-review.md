# 1.0.0-rc.9 candidate review · COPILOT-07 / COPILOT-08

Refs [Issue #52](https://github.com/weihaoting123-ctrl/human-online-relationships/issues/52)
and [design](../plans/2026-09-30-copilot-style-focus.md). This is a bounded,
stacked candidate on RC8, not formal 1.0 acceptance.

## Changes

- Three strict preference enums configure tone, empathy and reply length.
  Previews freeze normalized values for both one-shot and fixed-source grants.
  Changes invalidate previous previews, suggestions and grants; no implicit call.
- A local, explicitly synthetic example previews phrasing. Only preference
  enums persist; identities, chat text and consent never enter localStorage.
- Prompts avoid formulaic counseling, mechanical repetition and invented
  intimacy or experiences; real model quality remains unmeasured.
- A native, fresh, visible-window focus-loss reason allows suspension. Unknown
  input desktops, missing foreground identity, minimization and changed targets
  remain terminal. Watcher and OCR identities are separately compared.
- Old binding observations drain before suspension. Resume waits for that fence
  and a new stable title; source, configuration, archive and original ledger
  are revalidated. Resumed reads only advance the baseline, discarding away-time
  messages; original expiry and call counters remain unchanged.
- Late reads still check fatal identity, continuity and content changes even
  when focus is lost between the post-read guard and lock. Late model results
  cannot reappear, and failures remain terminal without retry.

## Independent review and synthetic evidence

Separate agents reviewed backend state/transport and native/frontend wiring.
Review found and drove fixes for mixed identity protocols, old observation
ordering, and a post-read pause race. No unresolved blocking finding remained
after targeted revalidation. This is AI-assisted review, not a human security
audit or proof of every possible interleaving.

- Focus/live/binding: 80 tests pass, including 18 focused pause/resume cases.
- Copilot regression snapshot: 273 tests pass in 180.849 seconds.
- Additional integration: 4 tests pass in 10.554 seconds, covering distinct
  identity protocols, observation ordering, repeated focus loss and style changes.
- Desktop Node plus catalog: 88/88 pass; JavaScript syntax and diff checks pass.
- Synthetic screenshots at 320px and 380px: no horizontal overflow or clipped
  controls, 40px controls, readable wrapping. Capture made zero API POSTs and
  used an ephemeral local fixture, not the real dashboard.
- Final full-suite results, exact source tree, publication scan, deployment and
  current-commit CI are recorded on the associated PR. Earlier or interrupted
  tests are not counted as final-suite evidence.
- The first full run executed 1,115 tests with 9 Windows symlink-privilege skips;
  two existing analysis-UI tests failed because string polling predicates used
  JavaScript eval under CSP. The fixture now passes function predicates with
  identical assertions. Production CSP is unchanged; a fresh full run is
  required and the failed run is not reported as passing.

## Boundaries and rollback

No real chat, title, source identity, screenshot, recording, credential or private
runtime history is published. Tests neither access WeChat nor call a provider.
No dependencies, export jobs, backups, model configuration or original records
are changed. Temporary script/screenshot artifacts are ignored and unpublished.

Only reviewed source files may be deployed after exact-base checks and a local
rollback copy. An existing deployed app router differs from public source;
only the three focus-route hunks are applied there, preserving unrelated code.
Service restart drops grants and never restores consent. Cross-version/native
identity, mixed-DPI and real model quality acceptance remain open. A draft
stacked PR and pending CI are not a merged release or a formal 1.0 tag.
