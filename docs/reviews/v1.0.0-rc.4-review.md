# 1.0.0-rc.4 candidate review · COPILOT-03

This candidate adds separately authorized, fixed-source recent-text suggestions.
It includes RC3's bounded one-click title calibration. It is not a formal 1.0
release, authenticated active-conversation detection, or real-model acceptance.
See [usage](../copilot.md), [specification](../superpowers/specs/2026-09-24-pinned-live-copilot.md)
and [implementation plan](../superpowers/plans/2026-09-24-pinned-live-copilot.md).

## Boundaries

The native title proposes an archive and supplies a best-effort pause fence;
same-name switches can be missed. An unchecked confirmation separately grants
one pinned native source account/contact, selected historical text, and new text
after the baseline, for at most 15 minutes / 6 attempts, 20 seconds apart. The
grant cannot silently switch sources or restart. Browser/manual mode retains
one-shot preview and confirmation. No grant is enabled during deployment.

The worker accepts only verifiable native direct-message mappings and a unique
account. It reuses cached keys, takes private read-only copies, queries only
snapshot databases, and limits the recent text tail. It does not read clipboard,
collect media, write WeChat records, discover keys through process scanning, hook
WeChat, download dependencies, or run full archival synchronization. Existing
cached passphrases can update local DPAPI-derived caches; local reads are not
claimed to cause zero local writes. Multi-account ambiguity stops.

Per-shard snapshots are not a globally atomic or complete event stream. The
worker's hard timeout may leave private temporary copies. Old/late rows, missing
overlap, changed identity/content, unknown senders, cross-shard same-second mixed
directions, and source timestamps outside the authorized interval fail closed.
Polling is best-effort and may take substantially longer than five seconds.

Cloud claims, scope revalidation, settings revocation, deduplication and budgets
are server-owned. Reader/network I/O does not hold the session lock. A failed or
unknown model request consumes an attempt and stops without retry. Stop cannot
recall an already-sent request. Outgoing text clears earlier pending suggestions
when observed; it cannot be detected before the next read. The sixth successful
result remains until stop, expiry, invalidation or observed outgoing text, with
no seventh cloud request. No automatic sending or paste exists.

## Independent review

Reader, backend and browser changes received separate spec/quality reviews.
Findings drove regressions for historical-time rewind, ambiguous cross-partition
ordering, nonzero server-ID rebinding, settings A-B-A revival, budget-exhausted
result retention and final grant-time upper bounds. No blocking finding remains
in the reviewed source. This is AI-assisted review, not a security certification.

## Controlled local deployment

Only an explicit source allowlist was copied after a local rollback copy. The
installed app had unrelated historical differences, so only the import, four
live routes, pre-read request guard and four mutation wrappers were patched.
Independent AST comparison confirmed that removing these additions reproduced
the previous method; existing import logic was preserved. New modules/UI match
the public source. No archival data, provider configuration, keys, backup,
scheduled task or WeChat process was changed.

The owned local dashboard was restarted after checking for active analysis jobs.
The four assistant assets match installed files over loopback HTTP; malformed
live requests are rejected before a source read. The native assistant was
launched with no conversation grant. Runtime syntax checks pass.

## Still unverified

Real source compatibility/latency with ongoing WeChat writes, successful real
header calibration, multiple monitors/mixed DPI/lock-screen recovery, and actual
paid-model suggestion quality/cost remain acceptance items. Synthetic success
must not be presented as evidence that those real paths were exercised. No real
chat, account identifier, credential, screenshot, recording or transcript was
used as a test fixture or published.
