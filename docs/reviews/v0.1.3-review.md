- 聚合统计与页面独立成模块；不改原导入、时间线、AI 分析契约或数据格式。复用已有严格时间解析和安全本机读取。
- 聚合测试先观察模块缺失失败；API 测试先观察接口 404；UI 测试先观察热度入口缺失，随后实现通过。
- 边界补充先复现默认空档案异常年份和请求 URL 多余参数，再修复。只计时间/类型，真实重复记录保留。
- 独立规格审查发现移入回收站/来源缺失的详情关闭路径未清理热度。用延迟响应测试复现后补清理；独立复核通过。
- 独立质量审查没有 Critical/Important；Minor 为折叠再展开会覆盖未应用的日期。补草稿状态及红→绿回归，保留输入且不自动请求。
- 额外对目录刷新不再包含当前会话的情形清理热度；红→绿回归通过。不借此重构旧详情展示逻辑。
- 最终独立质量复核无未解决 Critical/Important/Minor。源码审查不等于安全认证或实际屏幕阅读器人工验收。

## 范围限制

每次最多 366 个日历日；更长历史分段浏览，不静默缩减选区。默认以最新有效归档日为终点，不代表实时同步。
消息量不是聊天轮次、时长、已读、心理状态或关系质量。全档案排除数量与范围内图表数量分开说明。
沿用现有管理资料可见性检查及摘要扫描机制，不把此功能当作全资料库性能优化。

完整 regression 不等于真实微信采集、付费模型、macOS 或人工读屏验收。
公开发布与私人运行部署分开核验，本次不自动覆盖私人项目或重启其服务。
