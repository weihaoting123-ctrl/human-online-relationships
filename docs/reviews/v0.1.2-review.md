# v0.1.2 review / debug

范围为 DATA-01 第一阶段、[子任务 #22](https://github.com/weihaoting123-ctrl/human-online-relationships/issues/22)。使用独立公开源码、全合成材料和随机回环端口，不读取私人部署、运行微信采集、发送消息或调用云模型。

## 实施与独立审查

- 共享存储只负责已转换材料的保存，不重复归一化、不删除真实重复记录，不修改原生同步定位函数。
- 四个离线转换器接入完整暂存、提交与核验复用；网页保留自己的原件/统计流程，共享锁和身份辅助逻辑。
- 初始四 CLI 回归先复现不同内容写回同目录。网页回归先复现联系人/账号/来源身份混用、内容损坏复用及暂存候选问题；后续身份线索与 Windows 条件也先复现再修复。
- 实施自查补全转换前账号线索、完整表情材料集合、Windows 大小写文件别名及极端数字输入固定错误出口。
- 整合时修正共享锁不应改写调用者异常，以及 Windows 对本次暂存统计文件 fsync 所需的可写句柄；没有改动旧档案文件。
- 独立规范审查实际复现配置路径的目录联接被提前解析，以及网页复用 Windows 隐藏属性目录。保留词法配置路径并检查隐藏属性后，两项实际 Windows 回归均通过，规范复核通过。
- 独立质量审查没有 Critical/Important；唯一 Minor 为测试子进程就绪读取没有超时。增加 10 秒截止、终止与等待进程后回收读取线程，再清理管道；独立复核关闭，最终无未解决 Critical/Important/Minor。

## 边界

共同锁只约束接入的协作写入者，不能阻止其他程序改动资料。文件/目录同步与进程退出测试不是断电或磁盘损坏验收。符号链接权限跳过不算通过，Linux CI 需覆盖可用的文件系统链接语义；macOS 未实机验收。

不自动迁移旧清单，不改旧包 ID、管理库、显式合并、原生同步检查点、备份或定时任务。旧微信/QQ 在线提取器、显式输出文件、导入预检向导和整体工作台重组仍在后续需求池。网页旧 v1 包首次重新导入可能产生新包；详见 [保存契约](../import-storage.md)。

完整 review 在此指本轮关键边界的独立源码审查和合成回归，不等于形式化证明、渗透测试、真实微信采集或所有平台认证。公开软件发布与私人运行部署升级分别核验。
