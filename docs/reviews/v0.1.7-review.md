# v0.1.7 分析格式与安全诊断审查

状态：候选，未正式发布。[AI-04 / #34](https://github.com/weihaoting123-ctrl/human-online-relationships/issues/34) · [计划](../plans/2026-09-15-analysis-output-diagnostics.md)。本记录仅含源码与完全虚构的验证材料。

## 实现与审查

共享本机枚举与固定错误词汇，分开直接分析和摘要汇总契约；JSON 示例通过实际校验器。明确所有事件字段、证据日期/匿名序号配对、类型、长度、状态、关联、原因与限制。汇总不能改写已有事件或原有非空关联，压缩包缺少旧目标不等于该关联无效，完整事件图仍校验。

合成复现并修复合法事件的原起止日期未出现在所选证据中，汇总却据此拒绝不变事件的问题。允许原端点不会扩张证据配对集合，也不能借用别的事件日期改写当前事件。新增关联的先后与环检查、原因 limitations 沿用均有回归。

区分服务商响应结构、JSON、截断/未完成及字段规则失败；错误只含固定 code、允许的 schema 路径和本机说明，绝不包含模型原值、未知字段名或失败响应正文。调用墓碑、任务与部分报告保留安全诊断，API 再次过滤；历史文件不迁移、不伪造具体失败原因。

进度中的 attempted_calls 只统计新调用执行尝试，不证明已送达或计费；缓存复用不增加它。completed_calls 包含成功与复用。页面保留历史未知计数，标明分段/汇总与计划调用序号，失败不继续显示正在汇总，重复警告只显示一次。授权不自动勾选，旧预览不能在新提示词下使用。

独立交叉审查涵盖错误边界、缓存与计费锁、提示版本、部分结果保留；主代理复核 schema 改动、字段白名单、UI 与合成截图。所有自由文本仍是尽力最小化，不能将检查宣称为匿名性证明或安全认证。

## 兼容、费用与交付边界

保留旧四字段报告和旧缓存格式读取，严格时间线不降级伪装成功。提示词哈希改变意味着旧预览失效、旧调用指纹可能不复用；预算粗估纳入实际提示长度，预览明确提示重新计费风险。旧缓存和报告不删除，也不承诺升级后免费续跑。

只对私人运行区应用已核对的六个源码文件增量，保留其无关版本差异与源码回退；空闲后才重启本机服务。不更改连接、密钥、原始聊天、同步、备份、语音、数据目录或任务安排，不发起真实云调用。再次分析必须重新核对同一所选范围及计划，并由用户在本机流程明确确认。

公开只上传审阅过的源码、文档和虚构测试；不上传截图、日志、数据或私人 Git 历史。候选依赖前序未发布分支，远端 CI、基线合并、标签和 Release 均需另核验。未验证真实模型在本次所选内容上的成功率，不保证此后不存在网络、费用或输出格式失败。
