# 1.0.0-rc.10 · STAB-01 maintenance review

Refs [Issue #54](https://github.com/weihaoting123-ctrl/human-online-relationships/issues/54).
This is a bounded candidate on RC9, not formal 1.0 acceptance.

## Findings and changes

- Dialog read/save/error results are fenced by the exact selected conversation
  and request generation. A previous object's response cannot edit another.
- Trigger batches no longer replace authorized rolling reply context. Already
  observed active-session text is bounded to 200 rows / 20,000 characters;
  baseline and away-time text is excluded. Original expiry/call limits remain.
- Read-only status refresh preserves unchanged scope, draft, style and consent;
  changed configuration/source/module state or failed checks invalidate them.
  Preview errors use exact fixed local error mappings, not reflected bodies.
- Failed zero-result and interrupted/unknown analysis tasks remain discoverable.
  Task/report history has metadata filtering and pagination. Opening a stored
  task only reads local state; it does not restore consent or retry cloud work.
- Text corrections require a validated account/contact, stable server identity,
  exact source shard and unchanged sender/time/type/local identity. Historical
  source snapshots and derived versions remain intact. Ambiguous incoming
  variants remain conflicts and do not advance the source checkpoint.
  A synthesized array index never proves a source row. Older normalized rows
  without explicit proof cannot have conflicting text replaced; proof may be
  established only by an authorized fresh read with completely matching,
  nonempty text and unchanged source identity. Repeating a rejected conflict
  cannot manufacture that proof.
- Attachment catalogs bind to validated account identity. Legacy auto-migration
  needs consistent historical file identity plus an unchanged nonempty source
  whose full signature and content hash match its preserved archive object.
  Missing evidence, corrupt metadata, changed account or unsafe paths stop.
- Reply-assistant navigation, new-archive refresh notice, partial-media labels,
  and per-run transcription attachment counts make workflow state explicit.

## Verification

Regressions use wholly invented records, isolated temporary directories,
ephemeral loopback fixtures and mocked provider calls. The main failures were
reproduced before fixes. Independent cross-review also checks stale async
navigation, conflict provenance and migration fail-closed behavior. Exact full
suite, publication and current-commit CI results are recorded on the PR;
targeted tests or earlier commits are not substitutes for that gate.

RC9's Windows CI had one browser-console `ERR_NO_BUFFER_SPACE` failure;
Linux tests and both dependency audits passed. No console assertion is ignored
and production protections are not relaxed to turn that run green.
Thirty isolated repetitions passed, with no surviving browser context or
server listener. A test-only persistent HTTP handler reduced fixture socket
churn while preserving framing, authentication and security headers; six
synthetic transport checks cover it. This mitigates test resource pressure,
but does not prove the exact cause of the earlier runner failure. Production
HTTP behavior is unchanged.

## Deployment and boundaries

Only reviewed source and its matching dependency closure are deployed after
base-hash checks and a local rollback copy. An older local UI/router omitted
already-tested public import/navigation changes; matching core, shell, page,
import helpers and heatmap assets must move together. No private records,
configs, archives, schedules or dependencies are replaced. Service startup
does not restore a grant; existing data remains local and is not a test fixture.

Legacy catalogs without provenance stop with `media_account_binding_required`.
No automatic account guessing, whole-source rescan, data deletion, recovery,
or cloud call is performed to bypass that condition. Source corrections are
not a license to overwrite generic importer conflicts. Cross-version native
identity, mixed DPI, real model quality and formal-release acceptance remain
open. This is AI-assisted review, not a human security certification.
