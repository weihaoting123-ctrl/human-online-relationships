# 图表吸附读数（UI-03）

状态：受托维护范围已确认，已实现并进行候选验收。用户要求移动鼠标时显示对应数据，并有接近吸附的体验。依据项目托管规范，日常设计由代理决定。

## 选择与边界

选择共享的轻量 SVG 探针，而非逐点原生 title（命中区域小、提示延迟且难用于触屏）或引入整套图表库（增加依赖并改变现有图形）。保留现有苹果风格、曲线和统计口径。只读已传入浏览器的聚合数值，不增加 API、不读取聊天、不执行 AI、同步或备份。

首批覆盖会话每日轨迹、24 小时分布和双方互动比例，以及 AI 统计的日期／月份、小时、星期、消息构成、发言份额和换人间隔。独立媒体页面、AI 文字覆盖进度和历史报告原件不改；周密度／聊天热力图保留现有交互，后续按统一模块扩展。

## 交互

- 在绘图区内按横坐标吸附到最近的实际日期或类别；双曲线同时显示你、对方／其他成员、合计及完整日期。只展示输入统计值，不计算曲线插值。柱图空白间隙也可命中，零值可读取。
- 薄辅助线和空心高亮点是唯一新增视觉强调。数据卡放在图表容器内并约束边界；桌面使用侧边浮层，600px 以下的 SVG 图在下方预留读数区，避免遮挡中心点及显示时的布局跳动。标题完整，数值等宽，标签有文字和颜色，不能只靠颜色辨认。
- 指针移出隐藏；卡片本身可悬停。触屏轻点选择，拖动查看，允许纵向页面滚动，不强制捕获指针。键盘 Tab 聚焦整图，方向键逐项，Home/End 首末项，Escape 关闭且不顺带关闭会话详情。静态数值和报告表格继续保留。
- 单点、全零、无数据、长标签、缩放、窄屏和深色均不溢出。重新渲染销毁旧监听与卡片，切换会话不显示上一次的数值。不将每一个数据点变成 Tab 停靠点。
- 辅助线和卡片立即跟随真实点，不做读数追逐动画；减少动态效果时关闭过渡。不建立网络或存储副作用。

## 模块与视觉契约

新增 `chart-probe.js` 与 `chart-probe.css`，在所有图表使用者之前加载；主题色取现有 token。`ChartProbe.attach(svg, {points, plot})` 返回销毁函数：points 为按 x 升序的 `{x, label, rows:[{label,value,tone}], markers:[{y,tone}]}`，plot 为 `{left,right,top,bottom}`。`ChartProbe.detach(svg)` 支持重绘前清理。另提供 `ChartProbe.attachRows(container, items)` 供 HTML 横条共用数据卡与键盘行为，items 为 `{element,label,rows}`。任何文本只经 textContent。

视觉使用现有浅色底 #f5f5f7、卡片 #ffffff、正文 #1d1d1f、辅助 #606068、蓝 #0066cc、绿 #236c50，深色由主题映射。标题／正文沿用本机系统字体，数值采用 tabular-nums；不下载字体。与贴近鼠标浮窗相比，卡片在数据点边侧稳定停靠，减轻左右追逐。

## 验收与发布

先用合成浏览器用例观察缺失交互导致的失败，再实现；覆盖近邻命中、双侧值、边缘、零值、重新渲染、键盘、触摸、深色、小屏、减少动态效果、XSS 和无新增请求。独立 review 后跑完整合成回归与公开扫描。源码按 v0.1.5 候选记录（继承 v0.1.4 兼容补丁）；未通过对应远端 CI 不声称发布。私人运行目录只部署本功能补丁，不整包覆盖公开版本，也不重启已有分析任务。
