# COPILOT-02 · 一次点击的本机标题校准

目标：维护者要求代理完成校准，不要求提供真实聊天截图或手工标角。保留现有手动校准，新增显式点击的一次本机标题条定位。

边界：不启用 AI/回复模块，不读聊天正文、不保存截图、不输出识别文字、不连接云端；固定支持版本、唯一前台窗口、遮挡和几何变化检查继续生效。探测仅覆盖受支持布局的顶部保守条带，不能扩展到正文或整窗。布局/文字不明确则拒绝自动保存。

实现：worker 对两个独立标题条样本进行一致性检查，仅返回数值区域与不透明窗口标识；主进程重新核对目标几何和识别模式后原子保存。按钮具备瞬时用户手势保护，完成前不能被后台重试或普通轮询重新启动。

验收：先红后绿的 worker、reader、主控、preload 和 UI 用例；合成 OCR、取消/超时/多窗口/遮挡/陈旧结果拒绝；公开边界扫描与回归；私人部署仅替换已审阅源码，最后通过真实按钮做本机校准并仅核对安全状态。真实实机结果不得由合成测试代替。

回退：恢复上一版源码；保留已有区域设置、所有归档和模型配置。失败的自动校准不得覆盖旧区域。
