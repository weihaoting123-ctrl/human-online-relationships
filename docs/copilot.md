# 对话副驾（1.0 RC）

回复助手是独立的 Windows 桌面窗口，用已有归档和你手动补充的文字生成回复参考。它可以贴在微信窗口边缘，但窗口跟随不等于识别当前联系人或读取实时消息。当前版本必须手动选择会话，归档日期会一直显示在页面上。

## 安装与启动

先按 [项目快速开始](../README.md#快速开始windows) 配置项目的 Python 环境、依赖和本机控制台。桌面壳另需 Node.js/npm；Electron 依赖在 `desktop/copilot/package.json` 和锁文件中固定为 `44.4.5`。在项目根目录执行一次安装：

```powershell
npm --prefix .\desktop\copilot ci
```

安装会从依赖和 Electron 发行源下载运行时。该运行时不随仓库提交，启动脚本不会自动下载安装、升级依赖或注册开机启动。已有 `node_modules` 与锁文件不一致时，重新执行上述安装；不要用全局 Electron 替代项目内固定版本。

启动顺序：

```powershell
.\start_dashboard.ps1 -Port 8765
.\start_copilot.ps1 -Port 8765
```

两个脚本使用同一端口。`start_copilot.ps1` 检查本机页面和依赖，缺失时退出，不停止已有控制台，也不启动微信读取。关闭助手或从托盘选择退出只结束副驾，不关闭微信、控制台或既有同步任务。

也可直接访问 [浏览器版回复助手](http://127.0.0.1:8765/copilot/index.html)。浏览器版明确显示“浏览器模式”，不能吸附或跟随窗口；适合先配置模型、选择归档并核对发送流程。其他端口需相应更改地址。

## 使用一次回复建议

1. 在主控制台启用 **AI 分析** 并配置模型。回复助手模块默认关闭，需要在助手中明确点击“启用回复助手”；启用不会自动调用模型。
2. 展开助手，选择一个可见的归档会话。日期默认来自实际归档元数据，可缩小范围；没有可靠日期的归档暂不能发送。
3. 选择方向：轻松聊聊、拉近一点或自然邀约。默认最多取用 80 条文字，可设为 1–200 条。可手动补充最多 4,000 字的最新一句或想法。
4. 点击“核对本次发送范围”。此步骤在本机完成，显示所选日期、实际取用日期、条数、字符数、未取用与截断数量，以及接收方、模型和地址。
5. 确认范围与可能的服务商费用后，点击“确认发送并生成一次”。每个预览最多启动一次云端调用；失败或结果未知不会自动重试。再次生成需要新的预览和确认，可能重复计费。
6. 在三种回复和最多三个话题中取舍。点击“复制”才写入剪贴板，不读取剪贴板，也不粘贴到微信或发送消息。桌面版使用受用户点击约束的原生复制接口；复制失败会显示提示。

取样从所选范围的较新文字开始，总文字预算为 20,000 字符，包含补充内容。达到条数或字符上限时，较早文字可能未被取用，个别长消息可能截断；所选范围不代表范围内全量发送。当前副驾不取用图片、音频或语音转写。脱敏不能保证自由文本完全匿名，发送前仍需核对。

切换会话、日期、条数、方向或补充内容，会清除旧预览与建议；原生跟随目标身份变化时，还会清空会话选择和补充文字。旧请求即使稍后返回，也不会写回新的上下文。更改选择不能撤回已经开始的云端请求。

## 日常窗口行为

- 默认以 360×340 的紧凑窗口、贴边模式启动；先尝试右侧，再尝试左侧。紧凑模式保留一条可复制建议，展开后查看全部内容。
- 两侧空间不足时收成 156×48 气泡。只有主动点展开才允许 420×720 面板暂时占用部分目标窗口区域；消息、结果或状态更新不会自动展开。
- 拖动标题栏可移动助手，拖离边缘进入自由悬浮，靠近目标边缘可重新吸附。按钮保留可点击区域。
- 目标最小化、隐藏、切到其他应用、目标不唯一或窗口读取失效时，助手会隐藏或保持未绑定。它不移动、激活、嵌入、注入或关闭微信窗口。
- 默认不抢键盘焦点。主动进入输入控件才允许编辑聚焦；离开窗口或按 Esc 后恢复。没有声音、桌面通知或自动弹出提示。
- 可在托盘暂停/恢复跟随、切换位置模式、重新连接页面或退出。暂停会使已有确认失效，阻止新的生成；已开始的云调用不能据此保证取消。恢复后重新选择并核对上下文。

窗口状态只根据只读几何、可见性与进程身份决定。存在多个候选窗口时不会猜选账号。窗口位置和比例适配有自动化覆盖，但不同微信版本、显示器和 Windows 缩放组合仍可能存在差异。

## 当前限制与数据位置

当前未接入实时聊天捕获、联系人自动识别、OCR、微信输入控件或自动发送；不通过窗口标题读取聊天内容。切换同一个微信窗口内的联系人无法被副驾识别，因此必须自行更改会话选择。新消息只会通过已有、另行配置的归档同步进入记录，启动副驾不会运行或更改同步。

“同城”页尚未连接活动来源。可自行在补充文字中加入城市、兴趣和已核实的公开活动信息；页面不伪造实时活动或小红书来源。

回复、话题与补充内容只在本次会话内存中使用，不写入浏览器 `localStorage`，也不建立回复历史。后端预览只保留在进程内存中，十分钟过期，一次使用后失效。桌面运行配置位于项目的 `data/private/copilot/desktop-profile/`；它属于本机运行目录，不得提交到公开仓库。API Key 仍由原有 AI 配置在本机保存，不进入助手页面、报告或日志。

结构化输出校验和提示词约束用于减少心理评分、诊断、动机断言和不必要的个人信息；它们不能保证模型语义绝对正确。建议可能遗漏上下文或不合适，应由你判断、修改后再决定是否使用。

## 1.0 RC 验收清单

候选版验收只使用完全合成的档案、模拟服务商和自建测试窗口；不会操作真实微信或调用真实模型。

- [x] 默认模块关闭，依赖 AI 分析；缺失或非布尔真值的开关按关闭处理。
- [x] 预览不调用云端；生成必须显式确认，单次预览不能重复消费，失败不自动重试。
- [x] 展示实际抽样范围与略过/截断数量；输入、模型输出与错误文本不会作为 HTML 执行。
- [x] 会话与范围变化、原生身份变化和暂停会使旧授权失效；迟到结果被忽略。
- [x] 320px 布局、键盘标签页、紧凑建议复制、气泡尺寸及生产 CSP 下的浏览器合成测试。
- [x] 原生复制仅由用户操作触发；主进程检查可信页面和文本上限，不读取剪贴板。
- [x] 自建 Windows 窗口实测：显示不激活、移动与缩放跟随、最小化隐藏、恢复不抢焦点、切到其他应用隐藏、读取桥失效隐藏。另检查托盘位图能创建。
- [ ] 真实微信各版本及多显示器混合 DPI、虚拟桌面、锁屏恢复的人工兼容性验收；合成或单机测试不能替代这些证据。
- [ ] 经用户单独授权的真实模型输出质量与费用核验；离线模拟测试不代表已验证真实建议效果。

在项目根目录运行相关合成检查：

```powershell
$env:SHE_LOVE_ME_UI_TESTS = '1'
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_copilot_*.py'
npm --prefix .\desktop\copilot test
node --check dashboard/static/copilot/copilot.js
```

Windows 原生冒烟脚本 `desktop/copilot/tests/native-smoke.cjs` 会创建并操纵它自己的两个合成窗口，需要可交互桌面；它不使用真实微信。执行它时应显式知晓会短暂出现测试窗口。完整公开发布仍需遵循 [贡献与验收](../CONTRIBUTING.md) 和 [公开发布边界](public-release.md)，本页不代替整仓回归或版本发布核对。
