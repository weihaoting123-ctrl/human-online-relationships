# 对话副驾（1.0 RC）

回复助手是独立的 Windows 桌面窗口。默认用已有归档和手动补充的文字生成回复参考；RC4 增加另行授权的“固定会话限时辅助”，可读取新文字并更新建议，减少手动复制。RC9 增加语气、共情程度和回复长短设置，以及切屏后回到原会话的核验恢复。RC3 的一键本机标题校准继续保留。标题仅建议同名归档，不是当前微信身份认证；归档日期与限时授权状态分开显示。

## 日常打开：不需要命令行

本机控制台已运行、桌面组件已安装时，打开 [回复助手页面](http://127.0.0.1:8765/copilot/index.html)，点击页面顶部的 **“启动悬浮助手”**。如果助手已运行，按钮会显示 **“打开悬浮助手”**，打开已有窗口，不重复创建。

显式打开先显示展开的设置窗口，状态为“设置窗口 · 跟随已暂停”。点击窗口中的 **“跟随微信”**，再切回微信，即进入贴边跟随。暂停会清除旧建议和授权；恢复跟随不会自动开始读取新文字或调用模型，仍需重新核对会话并确认。助手不激活、移动或关闭微信。

刷新网页只检查状态，不启动窗口；缺依赖只提示，不下载。显示“已请求打开”表示本机服务已提交启动请求，并非已经确认窗口可见；超时或失败不会自动重试，请先查看桌面再决定是否重试。Linux/macOS 可继续使用浏览器模式，尚不支持该悬浮窗口。

## 首次安装与维护启动

先按 [项目快速开始](../README.md#快速开始windows) 配置项目的 Python 环境、依赖和本机控制台。桌面壳另需 Node.js/npm；Electron 依赖在 `desktop/copilot/package.json` 和锁文件中固定为 `44.4.5`。在项目根目录执行一次安装：

```powershell
npm --prefix .\desktop\copilot ci
```

安装会从依赖和 Electron 发行源下载运行时。该运行时不随仓库提交，启动脚本不会自动下载安装、升级依赖或注册开机启动。已有 `node_modules` 与锁文件不一致时，重新执行上述安装；不要用全局 Electron 替代项目内固定版本。

首次启动本机服务，或维护时使用下面的脚本。日常启动桌面助手优先使用上面的页面按钮：

```powershell
.\start_dashboard.ps1 -Port 8765
.\start_copilot.ps1 -Port 8765
```

两个脚本使用同一端口。`start_copilot.ps1` 检查本机页面和依赖，缺失时退出，不停止已有控制台，也不启动微信读取。关闭助手或从托盘选择退出只结束副驾，不关闭微信、控制台或既有同步任务。

也可直接访问 [浏览器版回复助手](http://127.0.0.1:8765/copilot/index.html)。浏览器版明确显示“浏览器模式”，不能吸附或跟随窗口；适合先配置模型、选择归档并核对发送流程。其他端口需相应更改地址。

## 使用一次回复建议

1. 在主控制台启用 **AI 分析** 并配置模型。回复助手模块默认关闭，需要在助手中明确点击“启用回复助手”；启用不会自动调用模型。
2. 展开助手，桌面版默认“识别当前微信标题”。首次按下文标记标题区域，随后切换聊天会自动建议唯一同名归档。也可切换手动模式选择会话。日期默认来自实际归档元数据，可缩小范围；没有可靠日期的归档暂不能发送。
3. 选择方向：轻松聊聊、拉近一点或自然邀约。在“想怎么说”中独立选择语气、共情程度和回复长度。默认最多取用 80 条文字，可设为 1–200 条。可手动补充最多 4,000 字的最新一句或想法。
4. 点击“核对本次发送范围”。此步骤在本机完成，显示所选日期、实际取用日期、条数、字符数、未取用与截断数量，以及接收方、模型和地址。
5. 确认范围与可能的服务商费用；自动模式还必须勾选“已核对当前微信账号、联系人与归档一致”，再点击“确认发送并生成一次”。预览和发送前都会重新识别，变化或失联会阻止本次请求。每个预览最多启动一次云端调用；失败或结果未知不会自动重试。再次生成需要新的预览和确认，可能重复计费。
6. 在三种回复和最多三个话题中取舍。点击“复制”才写入剪贴板，不读取剪贴板，也不粘贴到微信或发送消息。桌面版使用受用户点击约束的原生复制接口；复制失败会显示提示。

取样从所选范围的较新文字开始，总文字预算为 20,000 字符，包含补充内容。达到条数或字符上限时，较早文字可能未被取用，个别长消息可能截断；所选范围不代表范围内全量发送。当前副驾不取用图片、音频或语音转写。脱敏不能保证自由文本完全匿名，发送前仍需核对。

切换会话、日期、条数、方向、回复风格或补充内容，会清除旧预览与建议，也停止当前限时授权；原生跟随目标身份变化时，还会清空会话选择和补充文字。旧请求即使稍后返回，也不会写回新的上下文。更改选择不能撤回已经开始的云端请求。

“刷新状态”仅查询本机状态：同一归档、模型和功能状态未变时保留已选日期、草稿、风格、预览和限时授权。发现归档范围、模型或模块变化，或查询失败时，才清除已有确认并提示重新核对；发送和实时读取仍由后端检查原始来源与配置版本。重新加载整个页面会清空页面内存状态，不能用来恢复授权。

### 想怎么说（RC9）

- 说话风格：自然随口、轻松俏皮、温柔真诚、简洁直接。
- 共情程度：点到为止、刚刚好、多一点体贴；没有情绪线索时不强行安慰。
- 回复长度：一两句或稍展开。默认自然随口、刚刚好、一两句。

可展开固定的本机措辞示例，它不是 AI 结果，不会发送给服务商。偏好会显示在发送预览中并随确认封存；改风格不会自动重新生成。提示词减少客服套话、机械复述和连环反问，但不能保证每次模型输出都符合个人口味；候选仍可自行修改。

## 固定会话限时辅助（RC4）

完成下述标题校准、启用模块并匹配归档后，可以点击“核对并开启自动建议”。这与“生成一次”是两条不同的授权流程：

1. 预览固定会话、已选历史日期及实际抽样数量、服务商与模型。另行授权的新增范围从本次基线之后延续至到期，可跨午夜，但不会延长授权。此时不读取微信新文字、不调用模型。
2. 核对当前账号与来源联系人，勾选默认未选的持续授权框，再开启 **15 分钟 / 最多 6 次尝试**。限时模式不使用手工补充字段。缺少可信原生私聊映射、唯一账号、现有缓存或稳定副本时停止，不猜选、不扫描新密钥。
3. 首次只读建立近期基线，不因旧消息触发模型。RC8 起约每 2 秒在上一轮检查完成后再次检查；实际延迟由本机快照、数据库大小和模型响应决定，可能明显长于 2 秒，不保证即时。
4. 新的对方文字稳定至少 3 秒后才请求建议；两次调用至少间隔 20 秒，每批最多 20 条 / 4,000 字符，连同历史每次不超过 200 条 / 20,000 字符。已在本次授权的活动期间观察到的文字组成滚动上下文，保留上一轮对话与我方连续消息；达到总预算时从最早文字开始移出。我方新文字被观察到后会取消此前待生成内容并清空旧建议，但不删掉理解下一句所需的已授权上下文。首次基线和切屏暂停期间的文字不加入滚动上下文；读取期间无法即时知道尚未观察到的回复。
5. 限时授权不会自动换人。OCR 只尽力检测窗口或标题变化，同名等情况可能漏检；即使漏检，也只读取和发送已获准固定来源的文字，绝不会切到另一个来源。仅切到其他应用时按下文临时暂停，回到同一窗口和会话并核验后继续原授权。最小化、变更范围、手动停止、失联、来源/配置改变、读取不确定或模型失败后，需要重新核对授权，不自动恢复或重试。
6. 展开或紧凑窗均有停止入口。第六次成功结果保留并明确预算用完，不启动第七次请求；过期或停止清空建议。已经发出的请求不能收回，可能已计费，次数上限不是金额保证。

### 临时切屏（RC9）

仅能明确确认“微信窗口仍可见，只是切到其他应用”时，自动建议进入暂停：不再发起读取或模型请求，清除待生成内容与旧建议。返回原窗口、原稳定标题后重新核验固定来源、归档与配置；通过则继续原授权，不再次勾选、不重置 15 分钟倒计时或 6 次额度。恢复的首次读取只推进基线，离开期间消息不追发。

最小化、标题不确定、换人、来源变化、改风格/范围/模型、手动停止、到期、读取或模型失败仍终止，不能通过切回来绕过重新授权。授权不跨页面刷新或服务重启保存。在途请求不能撤回，可能已计费；迟到结果不重新显示。普通“生成一次”的预览不会随切屏恢复。

只支持已有只读同步生成并可核验账号与联系人映射的原生私聊，不支持群聊、手工导入或未经初始化的来源。仅文字，无图片、音频、转写或剪贴板采集；不写回微信，也不替用户发送。浏览器/手动选择模式保留单次预览，不提供限时入口。源记录通过普通只读文件复制形成私有快照，数据库查询只打开快照；没有 Hook、进程内注入、自动依赖下载或全量导出。持有现有同步锁时，不同时堆积读取任务。

“复用已有缓存”不等于本机零写入：读取器可用已保存口令为新分片验证并更新 DPAPI 派生缓存，多账号时可更新本机待确认元数据，但仍停止等待确认；不会扫描进程取得新口令，也不会把账号或缓存发往云端。迟到历史文字、游标无法衔接或跨分片同秒相反发言无法确定顺序时停止，不将其猜成新消息。

每个数据库副本分别验证一致性，不是所有分片的同一时点快照，不能证明已观察到所有实时事件。90 秒读取硬超时会停止；异常终止可能留下私有临时副本，不上传、不自动清理任何源记录。忙锁时本次授权停止，等待原同步完成后重新开启，不与每日同步争抢或自动堆积任务。

## 首次校准标题区域

以下标题校准本身不代表开启了限时授权。

仅桌面版、64 位 Windows 微信 **4.1.13.x** 支持本轮本机 OCR（96–288 DPI），还要求外窗与 DWM 可视顶边一致；部分最大化或非标准边框布局可能被拒绝。浏览器版与旧桌面桥保持手动选择；版本不符、多个窗口、遮挡或读不清时不猜选。需要系统已安装相应 Windows OCR 语言；启动过程不下载模型。

先展开副驾，点击“自动校准标题”，保持微信或副驾在前台且标题无遮挡。无需启用 AI 或回复模块。RC7 统一相对 DWM 可视边框的标准布局坐标：x=304、y=36、高40 DIP、宽最多480 DIP，右侧至少留160 DIP（窗口宽700–2000 DIP），避开上方窗口装饰。只复制屏幕上已显示的这块标题区域，不截取整窗、正文或整屏；输入桌面非活动、区域不在同一个实际显示器内或被遮挡时拒绝采集。小字号标题仅在内存中放大，坐标还原后仍用原图核对边缘。两次独立 OCR 与窗口状态一致才保存；为后续较长名称保留框内可用宽度，仍会拒绝截断/省略/多行结果。失败原因会留在按钮下方，不自动重试。

升级 RC7 后请重新点击“自动校准标题”或手动标记一次。旧区域文件保留，但因坐标基准不同不再复用；只有明确校准成功才保存新版本数值区域。自定义布局或大幅调整侧栏后，自动区域仍可能不适用，可重新手动标记。OCR 可能误读汉字，因此匹配只是同名候选，发送前仍须核对实际对象。

这是受支持标准布局的有限启发式定位，不证明文字一定属于联系人标题。自定义布局或姓名与界面文案混淆时应使用手动标记和身份核对；不使用正文或联系人列表作回退。

无法自动确定时，可手动标记：

1. 点击“标记标题区域”。保持微信或副驾在前台。
2. 鼠标移到微信右侧对话标题的左上角，按 **Ctrl+Alt+F8**。
3. 移到标题右下角，再按一次 **Ctrl+Alt+F8**。四周留少量空白，只圈标题，不圈聊天列表、搜索框或消息正文。区域高度需在 10–48 DIP、宽度 40–480 DIP，且处于窗口顶部。
4. 60 秒内完成。重复点击按钮可取消；快捷键冲突时停止校准，不覆盖其他应用的快捷键。布局或字体缩放变化、标题被截断时需要重新标记。

窗口移动后区域相对位置会跟随。未保存区域且未明确点击自动校准时不截取；自动校准只运行一次两轮标题条检查，校准后约每秒采样一次，连续两帧稳定才匹配。仅标题条位图在内存中交给系统 OCR，不写截图、不上传图片，不接入微信输入控件。最小化、暂停、失联或切到其他应用时清空当前 OCR 观察。RC9 对明确临时失焦单独暂停原限时授权，界面保留的归档标签不代表切走期间已识别当前聊天。

匹配使用 OCR 结果和归档的原始名称，不使用管理别名或模糊猜测。OCR 可能误认字形、合并中文间空格；一个唯一归档也可能与未归档的同名联系人混淆，因此始终显示为**待核对候选**。同名歧义时请选择手动模式，不能把标题识别当作微信账号或联系人 ID 验证。

## 日常窗口行为

- 普通脚本启动默认以 360×340 的紧凑窗口、贴边模式跟随；页面按钮显式打开则先进入暂停的展开设置窗口。跟随时先尝试右侧，再尝试左侧。紧凑模式保留一条可复制建议，展开后查看全部内容。
- 两侧空间不足时收成 156×48 气泡。只有主动点展开才允许 420×720 面板暂时占用部分目标窗口区域；消息、结果或状态更新不会自动展开。
- 拖动标题栏可移动助手，拖离边缘进入自由悬浮，靠近目标边缘可重新吸附。按钮保留可点击区域。
- 目标最小化、隐藏、切到其他应用、目标不唯一或窗口读取失效时，助手会隐藏或保持未绑定。它不移动、激活、嵌入、注入或关闭微信窗口。
- 默认不抢键盘焦点。主动进入输入控件才允许编辑聚焦；离开窗口或按 Esc 后恢复。没有声音、桌面通知或自动弹出提示。
- 可在托盘暂停/恢复跟随、切换位置模式、重新连接页面或退出。暂停会使已有确认失效，阻止新的生成；已开始的云调用不能据此保证取消。恢复后重新选择并核对上下文。

窗口状态只根据只读几何、可见性与进程身份决定。存在多个候选窗口时不会猜选账号。窗口位置和比例适配有自动化覆盖，但不同微信版本、显示器和 Windows 缩放组合仍可能存在差异。

## 当前限制与数据位置

没有接入消息窗全文 OCR、当前 UI 联系人 ID 认证、微信输入控件或自动发送。固定来源限时读取不等于任意当前会话自动识别；只查询获准来源近期文字，不回填归档。完整历史仍通过另行配置的同步更新，启动副驾不会运行或更改每日同步。

“同城”页尚未连接活动来源。可自行在补充文字中加入城市、兴趣和已核实的公开活动信息；页面不伪造实时活动或小红书来源。

回复、话题与补充内容只在本次会话内存中使用，不写入浏览器 `localStorage`，也不建立回复历史。RC9 仅将三个风格枚举写入 `copilot.reply-style.v1`，不包含聊天、身份、范围或授权。后端预览只保留在进程内存中，十分钟过期，一次使用后失效。桌面运行配置位于项目的 `data/private/copilot/desktop-profile/`；它属于本机运行目录，不得提交到公开仓库。API Key 仍由原有 AI 配置在本机保存，不进入助手页面、报告或日志。

标题区域只保存数值坐标和固定配置版本至 `data/private/copilot/header-region.json`。标题、识别会话与绑定令牌仅存内存，令牌在十秒未更新、候选/索引变化或程序重启后失效，不进入云端提示词、报告、日志或公开仓库。

限时授权、去重账本、近期文字与建议也只在进程内存里使用；读取器私有快照清理后不作为新归档保留。服务重启不会恢复授权。固定错误码不回显源路径、账号、正文或密钥。

结构化输出校验和提示词约束用于减少心理评分、诊断、动机断言和不必要的个人信息；它们不能保证模型语义绝对正确。建议可能遗漏上下文或不合适，应由你判断、修改后再决定是否使用。

## 1.0 RC 验收清单

候选版验收只使用完全合成的档案、模拟服务商和自建测试窗口；不会操作真实微信或调用真实模型。

- [x] 默认模块关闭，依赖 AI 分析；缺失或非布尔真值的开关按关闭处理。
- [x] 预览不调用云端；生成必须显式确认，单次预览不能重复消费，失败不自动重试。
- [x] 展示实际抽样范围与略过/截断数量；输入、模型输出与错误文本不会作为 HTML 执行。
- [x] 会话与范围变化、原生身份变化和暂停会使旧授权失效；迟到结果被忽略。
- [x] 320px 布局、键盘标签页、紧凑建议复制、气泡尺寸及生产 CSP 下的浏览器合成测试。
- [x] 原生复制仅由用户操作触发；主进程检查可信页面和文本上限，不读取剪贴板。
- [x] 合成标题/元数据、OCR 位图及桌面壳校准测试：无校准不采样，切换清空、同名不猜选、过期/迟到响应失效，自动候选逐次核对身份。
- [x] 自建 Windows 窗口实测：显示不激活、移动与缩放跟随、最小化隐藏、恢复不抢焦点、切到其他应用隐藏、读取桥失效隐藏。另检查托盘位图能创建。
- [ ] 真实微信各版本及多显示器混合 DPI、虚拟桌面、锁屏恢复的人工兼容性验收；合成或单机测试不能替代这些证据。
- [ ] 经用户单独授权的真实模型输出质量与费用核验；离线模拟测试不代表已验证真实建议效果。

在项目根目录运行相关合成检查：

```powershell
$env:SHE_LOVE_ME_UI_TESTS = '1'
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_copilot_*.py'
npm --prefix .\desktop\copilot test
node --check dashboard/static/copilot/copilot.js
```

Windows 原生冒烟脚本 `desktop/copilot/tests/native-smoke.cjs` 会创建并操纵它自己的两个合成窗口，需要可交互桌面；它不使用真实微信。执行它时应显式知晓会短暂出现测试窗口。完整公开发布仍需遵循 [贡献与验收](../CONTRIBUTING.md) 和 [公开发布边界](public-release.md)，本页不代替整仓回归或版本发布核对。

## 及时读取与静默更新（RC8）

开启固定会话限时辅助后，同一轮复用读取进程和已校验副本。未变化的来源跳过复制、查询与解码；有变化时只重建对应分片。界面每次检查完成后约 2 秒再次检查，实际新消息可见时间还取决于微信落盘、文件大小与校验耗时。

AI 生成期间继续检查新文字。尚有额度时，若读到我方已回复或对方继续发言，旧建议清除，稍后返回的过时建议丢弃；新的对方文字按已有间隔与额度等待下一次生成。额度用尽后仍保留最后成功结果并标注可能过时，我方回复仍会清除它。停止、切换或失效后，已经开始的调用仍可能计费。

状态只在阶段变化时更新，不抢焦点、播放通知或自动展开。15 分钟 / 最多 6 次尝试、至少 20 秒调用间隔仍适用。这里的 2 秒是检查间隔，不是模型回复速度承诺。

停止时关闭私有读取进程输入；正在进行的有界读取完成后清理临时副本。断开页面时进程最多空闲 30 秒，最长存活 15 分钟。异常终止可能留下私有临时文件，不会把它们当作可恢复的授权。见[实现与验收](plans/2026-09-27-copilot-reading.md)。
